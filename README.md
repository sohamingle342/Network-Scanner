# 🌐 Network Scanner

A professional Python-based Network Scanner built using **Nmap**. It provides multiple scan modes, vulnerability detection, report generation, SQLite scan history, and logging.

---

# 🚀 Features

- ⚡ Fast Scan
- 🔍 Service Version Detection
- 💻 Operating System Detection
- 🌍 Full Port Scan
- 🎯 Custom Port Scan
- 📡 Multiple IP Address Scanning
- 📶 Ping Sweep
- 🛡 Basic Vulnerability Detection
- 📄 TXT Report Generation
- 📊 CSV Report Generation
- 📑 JSON Report Generation
- 🗄 SQLite Database Storage
- 📝 Scan Logging
- 🎨 Colored Terminal Output

---

# 🛠 Technologies Used

- Python

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/sohamingle342/Network-Scanner.git
```

Move into the folder

```bash
cd Network-Scanner
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
