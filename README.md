# Network Scanner

A Python-based Network Scanner built using Nmap.

## Features

- Fast Scan
- Service Version Detection
- OS Detection
- Full Scan
- Custom Port Scan
- Multiple IP Scan
- Ping Sweep
- Vulnerability Checks
- TXT Reports
- CSV Reports
- JSON Reports
- SQLite Scan History
- Logging System

## Technologies Used

- Python
- python-nmap
- SQLite3
- Colorama
- JSON
- CSV

## Installation

```bash
pip install python-nmap colorama
```

Run:

```bash
python main.py
```
